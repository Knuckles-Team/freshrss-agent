# CONN-FRESHRSS-AGENT-SDK-CENTRALIZATION — Requirements

Governing specification: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-FRESHRSS-AGENT-SDK-CENTRALIZATION-R001` | **Governed HTTP.** The connector must reach FreshRSS only through the SDK governed HTTP client in `freshrss_agent/api/api_client_base.py`. It must not import `requests`. Caller chain: arbora fleet.call -> a FreshRSS MCP tool (freshrss_agent/mcp_server.py) -> freshrss_agent/auth.py::get_client -> freshrss_agent/api/api_client_base.py::FreshRSSClientBase, whose __init__ builds self.session with create_http_client. Shape: FreshRSSClientBase.__init__ uses scion_sdk.http.client.create_http_client with HttpClientOptions and resolve_tls_profile("freshrss"); FreshRSSApi subclasses it, and no module imports requests. | `tests/test_sdk_centralization.py::test_api_client_uses_sdk_http_client` must observe an SDK client and no `requests` import. |
| `CONN-FRESHRSS-AGENT-SDK-CENTRALIZATION-R002` | **Adopt scion-sdk 0.10.0 import paths.** freshrss-agent must import only paths that exist in `scion-sdk` 0.10.0 and must raise its floor to that release. The release removes the pre-layer paths without an alias (`SCION-CENTRALIZED-CAPABILITIES-R046`). Stage: dependency and import adoption. Edits, by file: `freshrss_agent/api/api_client_base.py`: `create_http_client` to `build_http_client(options)`; `freshrss_agent/auth.py`: `create_http_client` to `build_http_client(options)`. Raise the `pyproject.toml` requirement `scion-sdk[mcp]>=0.9.0` to `scion-sdk>=0.10.0,<0.11.0` with the same extras and regenerate `uv.lock`. A client built by the old factory keeps its options argument; `build_http_client(options, async_=True)` returns the async client. No wrapper, alias or fallback import stays. Caller chain: the connector entry point `freshrss_agent` -> its modules above -> the public `scion_sdk` modules. Shape: import edits in the files named, one `pyproject.toml` edit and one lock edit; the new test reuses `ast` from the standard library. Depends on: SCION-CENTRALIZED-CAPABILITIES-R046. | Test: `tests/test_scion_sdk_0_10_imports.py::test_every_scion_sdk_import_resolves_on_the_pinned_release` (L2) parses every Python file of `freshrss_agent` and `tests` and asserts each imported `scion_sdk` module resolves with `importlib.util.find_spec`. |
